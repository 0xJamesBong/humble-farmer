# humble-farmer

Systematic crypto trading focused on **FreqTrade** as the core engine (Binance, majors, 4h, backtest, hyperopt, paper/live, FreqUI/Telegram).

## Layout

- **[freqtrade/](freqtrade/)** — Docker Compose, `user_data/config.json`, and Python strategies. Start here.
- **[contracts/](contracts/)** — Reserved for future **external signal** contracts (on-chain, Rust pipelines, etc.). Not used by FreqTrade for day-to-day trading.
